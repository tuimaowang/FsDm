# DirectX 9 动画演示

此项目是独立的 Windows x64 示例，使用 Visual Studio C++ 和 DirectX 9 绘制静态场景、实时动画与中文说明。中文文本通过 Windows 字体生成透明纹理，不需要额外安装旧版 D3DX 字体库。

## 编译

在 PowerShell 中运行：

```powershell
.\Goujian.ps1
```

程序输出位置：

```text
bin\Release\DonghuaYanshi.exe
```

也可以在 Visual Studio 中打开 `Dx9Donghua.vcxproj`，选择 x64 和 Release 后生成。

## 操作

- 空格：暂停或继续动画。
- **F8** 或窗口菜单“控制 → 停止帧提交”切换停止、恢复。菜单勾选和标题“帧提交已停止”表示开关已开启。
- 左方向键：降低动画速度。
- 右方向键：提高动画速度。
- **R** 恢复初始角度、默认速度并恢复帧提交及播放。
- Esc：退出。

窗口支持缩放。静态网格和说明文字保持不动；立方体、轨道光点、波形柱与时间指示点随时间更新。

## 测试帧提交

程序启动后持续绘制并调用 Direct3D 9 的 `Present`，向显示系统提交新画面。
按 F8 停止后，动画时间、绘制和 `Present` 一起停止，窗口继续处理菜单、键盘、缩放和关闭操作。
再次按 F8 从停止的位置继续。停止期间发生的缩放会在恢复提交时应用到绘图设备。

可以绑定此窗口并调用 `GetFrameNumber(1)`，观察停止、恢复前后的采集编号。
原有空格键控制立方体等动画的角度暂停，时间指示点和帧提交仍会继续。
