【模板预加载：保持上面的 DX 绑定；找图前等到 GPU已缓存】
SetPath("C:\Users\Administrator\Documents\DaMo\FsDm")
LoadPic("test.bmp") // 预加载，1 成功；后续直接使用内存模板。
FindPic(0, 0, 834, 419, "test.bmp", "000000", 0.9, 0) // 绑定后执行；count=1 找到，count=0 无命中，非零 status 为错误。
FreePic("test.bmp") // 释放模板，1 成功；下次找图会从文件重新加载。
LoadPic("test*.bmp") // 按通配符预加载；1 全部成功，0 有失败，已成功的项保留。
FreePic("test*.bmp") // 释放当前目录内名称匹配的模板。

LoadPicByte(0x实际BMP首地址, 实际BMP文件字节数, "memory.bmp") // 替换成目标进程内的实际地址和大小后输入；1 成功，原内存随后可释放。
FindPic(0, 0, 834, 419, "memory.bmp", "000000", 0.9, 0) // 查找内存加载的模板，不需要 memory.bmp 文件。
FreePic("memory.bmp") // 释放内存模板。

【新增图色接口：保持绑定且已有画面】

GetScreenData(0, 0, 100, 100) // 返回本线程的 CPU 数据地址；0 失败，每像素为 B、G、R、0 四字节。
IsDisplayDead(0, 0, 100, 100, 2) // 检查 2 秒；1 一直不变，0 有变化或失败。
MatchPicName("test*.bmp") // 无需绑定；返回 SetPath 目录内匹配的 BMP 文件名，以 | 分隔。
