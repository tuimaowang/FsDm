BindWindow

函数简介：

绑定本进程的指定窗口，同时选择采集方式；绑定成功后才开始采集。

函数原型：


int WINAPI BindWindow(HWND hwnd, const char* display, const char* mouse, const char* keypad, int mode);

参数定义：

  • hwnd：本进程的有效窗口句柄；x64 不得截断成 32 位。
  • display："dx"、"obs" 或 "wgc"，直接选择对应采集方式，区分大小写。当前不支持 "gdi"、"gdi2"、"normal"、"dx2"。
  • mouse：接受 "normal"、"windows" 或 "dx"；当前仅校验并保存该配置，不执行鼠标操作，建议填写 "normal"。
  • keypad：接受 "normal"、"windows" 或 "dx"；当前仅校验并保存该配置，不执行键盘操作，建议填写 "normal"。
  • mode：0 或 1。

返回值：

  • 1：绑定成功，可能仍在等待首帧。
  • 0：绑定失败。

示例：


BindWindow(0x实际窗口句柄, "dx", "normal", "normal", 0)
UnBindWindow()
BindWindow(0x实际窗口句柄, "wgc", "normal", "normal", 0)
UnBindWindow()
BindWindow(0x实际窗口句柄, "obs", "normal", "normal", 0)

注意： 同进程只保留一个绑定。相同参数重复绑定成功；改变参数（包括采集方式）须先解绑。失败绑定不改变原绑定及其采集方式。最多等待初始化 7 秒，不等待首帧。绑定线程退出或窗口销毁会自动解绑。mouse 和 keypad 目前只作为配置值校验、保存并参与重复绑定比较，不实现鼠标或键盘操作；实际调用建议均填写 "normal"。其中 "dx" 只是可接受的字符串，不代表已实现 DX 鼠标或键盘模式。

完整调用实例：请参阅BindWindow 所属工作流，其中包含前置设置、调用及结果/资源处理。
