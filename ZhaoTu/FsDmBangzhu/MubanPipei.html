OpenCV 模板匹配函数

模板匹配是在采集画面中逐位置比较小图与画面像素，找到分数达到阈值的位置。四个接口使用 OpenCV 在 CPU 上执行模板匹配。

调用前通过 BindWindow 绑定窗口并等待采集首帧，使用 SetPath 设置模板基础目录。

四个 CvFindPic 入口的完整绑定、模板准备、结果读取和释放流程见完整调用实例。

  • CvFindPic 返回首个匹配。
  • CvFindPicEx 返回最多 1500 个匹配。
  • CvFindPicMem 使用已登记的内存模板，返回首个匹配。
  • CvFindPicMemEx 使用已登记的内存模板，返回最多 1500 个匹配。

共用参数

参数含义
x1, y1搜索区域左上角的客户区物理像素坐标。
x2, y2搜索区域右下角坐标，右下边界不包含。超出客户区的部分按现有区域规则截断。
pic_nameUTF-8 模板名称，多个名称用 | 分隔。支持相对于 SetPath 的路径、绝对路径和已登记的模板别名，按列表顺序查找。
sim匹配分数阈值，范围为 0.1～1.0。分数达到阈值即命中。
dir扫描方向，取值为 0～3，详见下表。
dir扫描顺序
0从左到右，从上到下
1从左到右，从下到上
2从右到左，从上到下
3从右到左，从下到上

匹配分数

分数按有效模板像素的 RGB 通道平方误差计算，浮点计算使用少量误差容限。

分数 = 1 - RGB 各通道平方误差之和 / (有效像素数 × 3 × 255²)

模板支持项目现有的 BMP24、PNG、JPG/JPEG 格式。PNG 的 alpha 为 0 的像素跳过，半透明像素按 RGB 比较。BMP24 沿用四角同色的透明色规则，纯色模板按不透明处理。模板按原始尺寸匹配。

每次调用将采集画面读回 CPU 后执行匹配，此路径独立于 SetFindBackend 的选择。

共用返回值

返回 const FsTongyongJieguo*。先检查指针，再检查 status 与 count。

  • nullptr 表示结果分配失败。
  • status == FS_CHENGGONG 表示查找执行成功，count == 0 表示无匹配。
  • 每条结果的 id 为输入模板列表的下标，x/y 为模板左上角坐标，file 为本次输入的模板名称。
  • 有效字段为 FS_JG_ID | FS_JG_XY | FS_JG_FILE。使用后调用 FreeResult 释放结果。
  • 模板按输入列表顺序处理。单张无法加载时跳过，全部无法加载时返回 FS_JIAZAI_SHIBAI。
  • Ex 版本最多返回 1500 项，包含可能重叠的匹配。

CvFindPic

函数简介

在指定区域查找文件模板，返回按模板列表顺序和扫描方向找到的首个匹配。参数和结果字段见本页共用说明。

函数原型

const FsTongyongJieguo* WINAPI CvFindPic(int x1, int y1, int x2, int y2, const char* pic_name, double sim, int dir);

示例

const FsTongyongJieguo* result =
    CvFindPic(0, 0, 800, 600, "target.bmp", 0.95, 0);
if (result) {
    if (result->status == FS_CHENGGONG && result->count > 0) {
        // 读取首个匹配位置，坐标对应模板左上角。
        int x = result->items[0].x;
        int y = result->items[0].y;
    }
    FreeResult(result);
}

CvFindPicEx

函数简介

在指定区域查找文件模板，返回最多 1500 个匹配。多模板时先返回第一张模板的匹配，再处理下一张模板。参数和结果字段见本页共用说明。

函数原型

const FsTongyongJieguo* WINAPI CvFindPicEx(int x1, int y1, int x2, int y2, const char* pic_name, double sim, int dir);

示例

const FsTongyongJieguo* result =
    CvFindPicEx(0, 0, 800, 600, "target.bmp|other.png", 0.95, 0);
if (result) {
    if (result->status == FS_CHENGGONG) {
        for (unsigned i = 0; i < result->count; ++i) {
            // 按返回顺序读取每个模板的匹配位置。
            int x = result->items[i].x;
            int y = result->items[i].y;
        }
    }
    FreeResult(result);
}

CvFindPicMem

函数简介

使用内存模板的登记别名查找首个匹配。先调用 LoadPicByte，将完整 BMP 文件字节登记为别名，再将别名传给 pic_name。参数和结果字段见本页共用说明。

函数原型

const FsTongyongJieguo* WINAPI CvFindPicMem(int x1, int y1, int x2, int y2, const char* pic_name, double sim, int dir);

示例

// bmpData 指向完整 BMP 文件字节，bmpSize 为字节数。
if (LoadPicByte(reinterpret_cast<uintptr_t>(bmpData), bmpSize, "memory.bmp") == 1) {
    const FsTongyongJieguo* result =
        CvFindPicMem(0, 0, 800, 600, "memory.bmp", 0.95, 0);
    if (result) {
        if (result->status == FS_CHENGGONG && result->count > 0) {
            int x = result->items[0].x;
            int y = result->items[0].y;
        }
        FreeResult(result);
    }
    FreePic("memory.bmp");
}

CvFindPicMemEx

函数简介

使用内存模板的登记别名查找，返回最多 1500 个匹配。通过 LoadPicByte 登记完整 BMP 文件字节后，将别名传给 pic_name，多个别名用 | 分隔。参数和结果字段见本页共用说明。

函数原型

const FsTongyongJieguo* WINAPI CvFindPicMemEx(int x1, int y1, int x2, int y2, const char* pic_name, double sim, int dir);

示例

// bmpData 指向完整 BMP 文件字节，bmpSize 为字节数。
if (LoadPicByte(reinterpret_cast<uintptr_t>(bmpData), bmpSize, "memory.bmp") == 1) {
    const FsTongyongJieguo* result =
        CvFindPicMemEx(0, 0, 800, 600, "memory.bmp", 0.95, 0);
    if (result) {
        if (result->status == FS_CHENGGONG) {
            for (unsigned i = 0; i < result->count; ++i) {
                int x = result->items[i].x;
                int y = result->items[i].y;
            }
        }
        FreeResult(result);
    }
    FreePic("memory.bmp");
}

内存模板通过 FreePic 释放。结果对象通过 FreeResult 释放。
