完整调用实例

以下示例按实际操作流程组织。工作台代码块逐行输入；工作台会显示返回值并自动释放本次通用结果。C++ 代码块用于包含交付头文件并链接或动态加载 ZhaoTu.dll 的业务程序，窗口句柄、路径和模型文件应替换为本机实际值。

除屏幕文件 OCR、模板内存和底层 GPU 接口外，找图、找色、窗口 OCR、找字及 YOLO 均先绑定目标窗口并等待首帧。普通结果先检查指针和 status，再读取 count/items/fullText，最后调用 FreeResult；独立字符串使用完后调用 FreeAllStringResults。解绑前应释放仍持有的 GPU 帧租约。

设备占用率测试

适用函数 GetCpuUsage、GetGpuUsage。加载 ZhaoTu.dll 后即可测试，每次各采样约 200 毫秒，返回 0～100 的小数，-1 表示失败。CPU 统计整机全部逻辑处理器平均忙碌时间，GPU 汇总各进程后取所有显卡中最繁忙引擎的占用率。

// 工作台逐行执行，两个读数各自对应独立的采样时间窗口。
GetCpuUsage()
GetGpuUsage()

C++ 项目包含 ZhaoTu.h，链接 ZhaoTu.lib，并部署配套 ZhaoTu.dll。下面是可直接运行的完整程序。

#include "ZhaoTu.h"
#include <cstdio>

int main() {
    const double cpu = GetCpuUsage();
    const DWORD cpuError = GetLastError();
    const double gpu = GetGpuUsage();
    const DWORD gpuError = GetLastError();
    if (cpu < 0.0) std::printf("CPU sample failed, error=0x%08lX\n", cpuError);
    else std::printf("CPU %.2f%%\n", cpu);
    if (gpu < 0.0) std::printf("GPU sample failed, error=0x%08lX\n", gpuError);
    else std::printf("GPU %.2f%%\n", gpu);
    return cpu < 0.0 || gpu < 0.0 ? 1 : 0;
}

工作台排序与类别名转换

在上面的 UnBindWindow 和 AiYoloFreeModel 之前输入下面的命令。工作台会自动释放前一次调用返回的字符串，跨调用传递结果时，把检测输出复制为字符串参数。以下类别 0 和 2 对应附带模型的 person 与 car。

// 以下条目用于演示格式，实际使用时复制本次检测返回的字符串。
AiYoloSortsObjects("0,0.920000,300,10,20,20|2,0.850000,100,30,20,20", 0)
AiYoloObjectsToString("0,0.920000,300,10,20,20|2,0.850000,100,30,20,20")

上例 height=0，x=100 的条目先输出，随后是 x=300 的条目。height 大于 0 时先按行高分组，各行按 x 排序。名称转换返回 person|car，顺序按传入的原始字符串确定。

C++ 检测、排序、名称转换及保存标注图片

本例在目标窗口所属进程运行，包含交付头文件并链接 ZhaoTu.lib，部署配套 DLL。示例独占绑定和结果释放时机，业务程序应协调其他线程的模型选择和结果读取。

#include "FsDmJiekou.h"
#include <cstdio>

// 在目标窗口所属进程调用，hwnd 为实际窗口句柄。
// 包含 FsDmJiekou.h，链接 ZhaoTu.lib，并部署配套 DLL 与模型。
bool CeshiYoloWanzheng(HWND hwnd) {
    if (!AiYoloSetVersion("v5-7.0")) return false;
    if (!AiYoloSetModel(0, R"(C:\Users\Administrator\Documents\DaMo\FsDm\out\build\bin\Release\YoloMoxing\yolov5n.onnx)", "")) {
        std::printf("%s\n", GetOcrError());
        FreeAllStringResults();
        return false;
    }
    if (!AiYoloUseModel(0)) {
        AiYoloFreeModel(0);
        return false;
    }
    if (!BindWindow(hwnd, "dx", "normal", "normal", 0)) {
        AiYoloFreeModel(0);
        return false;
    }
    // 绑定成功后等待首张可用快照，最多约一秒。
    bool ready = false;
    for (int attempt = 0; attempt < 100; ++attempt) {
        FsZhuangtai state{};
        state.size = sizeof(state);
        if (GetStatus(&state) == FS_CHENGGONG && state.result == FS_CHENGGONG
            && state.bound && state.hasFrame) {
            ready = true;
            break;
        }
        Sleep(10);
    }
    bool ok = false;
    if (ready) {
        const char* objects = AiYoloDetectObjects(0, 0, 834, 419, 0.5, 0.45);
        // 立即读取本线程检测诊断，避免后续调用覆盖诊断。
        const char* error = GetOcrError();
        if (objects && error && *error == '\0') {
            std::printf("objects=%s\n", objects);
            const char* sorted = AiYoloSortsObjects(objects, 20);
            const char* names = sorted ? AiYoloObjectsToString(sorted) : nullptr;
            if (sorted && names) {
                std::printf("sorted=%s\nnames=%s\n", sorted, names);
                ok = (*objects == '\0') || (*sorted != '\0' && *names != '\0');
                if (ok) {
                    ok = AiYoloDetectObjectsToFile(0, 0, 834, 419, 0.5, 0.45,
                                R"(C:\Users\Administrator\Documents\DaMo\FsDm\yolo_result.bmp)", 0) == 1;
                    if (!ok) std::printf("%s\n", GetOcrError());
                }
            }
        } else {
            std::printf("%s\n", error ? error : "结果内存分配失败");
        }
    }
    // 本例全部结果读取结束后统一释放。
    FreeAllStringResults();
    UnBindWindow();
    const bool freed = AiYoloFreeModel(0) == 1;
    return ok && freed;
}
