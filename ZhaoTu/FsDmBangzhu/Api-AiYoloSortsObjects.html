AiYoloSortsObjects

函数简介

对检测字符串中的目标按分行规则和横坐标重新排序，保留每个目标原有字段。

函数原型

const char* WINAPI AiYoloSortsObjects(const char* objects, int height);

参数定义

参数含义
objects检测字符串，格式为 "类别编号,置信度,x,y,w,h|..."，可以传入 AiYoloDetectObjects 的结果。空字符串表示空列表。
height非负整数，单位为客户区像素。大于 0 时，先按 y、x 排序，以当前行首个目标的 y 为基准，后续目标与基准 y 的差达到 height 时另起一行，各行内部按 x 升序排列。传 0 时将全部目标作为一行，最终按 x 升序排列。

返回值与结果处理

  • 成功时返回重新排序后的独立字符串，各项字段保留原始文本。
  • 输入为空列表或解析失败时返回空字符串，分配失败可能返回 nullptr。此函数没有更新 GetOcrError 的诊断信息。
  • 返回值为 DLL 分配的独立 UTF-8 字符串，分配失败可能返回 nullptr。使用完后调用 FreeAllStringResults() 或 FreeAllResults()。全量释放会同时回收其他线程持有的字符串和通用结果，调用前须完成所有结果读取。工作台会自动显示并释放本次字符串结果。

作用范围与调用说明

  • 这是检测结果的排序接口，可直接处理已取得的字符串。
  • height=0 的实际结果为全部目标按 x 排序。同一 x 的条目保持前面 y、x 预排序产生的先后顺序。
  • 输入末尾须紧跟最后一个目标字段，尾部多余的 | 会使解析失败。

完整 C++ 调用示例

路径使用本项目 Release 目录附带的 FP32 模型，按实际文件位置和窗口区域调整。本例独占绑定和全量结果释放时机，调用方须在目标窗口所属进程中运行。

#include "FsDmJiekou.h"
#include <cstdio>

// 在目标窗口所属进程调用，hwnd 为实际窗口句柄。
// 包含 FsDmJiekou.h，链接 ZhaoTu.lib，并部署配套 DLL 与模型。
bool CeshiAiYoloSortsObjects(HWND hwnd) {
    if (!AiYoloSetVersion("v5-7.0")) return false;
    if (!AiYoloSetModel(0, R"(C:\Users\Administrator\Documents\DaMo\FsDm\out\build\bin\Release\YoloMoxing\yolov5n.onnx)", "")) {
        std::printf("%s\n", GetOcrError());
        FreeAllStringResults();
        return false;
    }
    if (!AiYoloUseModel(0)) {
        AiYoloFreeModel(0);
        return false;
    }
    if (!BindWindow(hwnd, "dx", "normal", "normal", 0)) {
        AiYoloFreeModel(0);
        return false;
    }
    // 绑定成功后等待首张可用快照，最多约一秒。
    bool ready = false;
    for (int attempt = 0; attempt < 100; ++attempt) {
        FsZhuangtai state{};
        state.size = sizeof(state);
        if (GetStatus(&state) == FS_CHENGGONG && state.result == FS_CHENGGONG
            && state.bound && state.hasFrame) {
            ready = true;
            break;
        }
        Sleep(10);
    }
    bool ok = false;
    if (ready) {
        const char* objects = AiYoloDetectObjects(0, 0, 834, 419, 0.5, 0.45);
        // 立即读取本线程检测诊断，避免后续调用覆盖诊断。
        const char* error = GetOcrError();
        if (objects && error && *error == '\0') {
            const char* sorted = AiYoloSortsObjects(objects, 20);
            if (sorted) {
                std::printf("sorted=%s\n", sorted);
                ok = (*objects == '\0') || (*sorted != '\0');
            }
        } else {
            std::printf("%s\n", error ? error : "结果内存分配失败");
        }
    }
    // 本例全部结果读取结束后统一释放。
    FreeAllStringResults();
    UnBindWindow();
    const bool freed = AiYoloFreeModel(0) == 1;
    return ok && freed;
}
