GetDictCount

函数简介：

获取指定字库中已加载的字形条目数量。

函数原型：


int WINAPI GetDictCount(int index);

参数定义：

  • index：字库编号，0～99。

返回值：

  • 大于或等于 0：字形条目数；未加载时为 0。
  • 编号无效也返回 0，可通过 GetOcrError 区分。

示例：


GetDictCount(0)

注意： 计数字形条目，不一定等于去重后的字符数量。当前单个字库最多 10000 个字形。
