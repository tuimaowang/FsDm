SetOcrModelFiles

函数简介：

分别指定方向分类、文字检测、文字识别模型和字符字典文件，登记一组 PP-OCRv3 兼容 OCR 模型。

函数原型：

int WINAPI SetOcrModelFiles(int index, const char* classifier_path,
    const char* detector_path, const char* recognizer_path, const char* dictionary_path);

参数定义：

  • index：模型编号，0～99。
  • classifier_path：方向分类 ONNX 文件路径；不使用方向分类时传 NULL 或空字符串。
  • detector_path：文字检测 ONNX 文件路径。
  • recognizer_path：文字识别 ONNX 文件路径。
  • dictionary_path：与识别模型匹配的字符字典文本文件路径。

返回值：

  • 1：模型文件和字典登记成功。
  • 0：编号、路径或字典无效。

示例：

SetOcrModelFiles(1,
    "C:\\Users\\Administrator\\Documents\\DaMo\\ocr_model\\models10\\cls.onnx",
    "C:\\Users\\Administrator\\Documents\\DaMo\\ocr_model\\models10\\detEN.onnx",
    "C:\\Users\\Administrator\\Documents\\DaMo\\ocr_model\\models10\\RecEN.onnx",
    "C:\\Users\\Administrator\\Documents\\DaMo\\ocr_model\\models10\\KeysEN.txt")
UseOcrModel(1)

注意： 四个参数均为文件路径，不是目录；分类模型可选。建议使用绝对路径；相对路径按调用进程的当前目录解析。此接口登记 PP-OCRv3 兼容组件，不代表任意 ONNX 文件组合都兼容。文件是否可用于当前实现，会在首次 OCR 创建会话时进一步校验；成功登记后还需调用 UseOcrModel 选中该编号。

完整调用实例：请参阅SetOcrModelFiles 所属工作流，其中包含前置设置、调用及结果/资源处理。
