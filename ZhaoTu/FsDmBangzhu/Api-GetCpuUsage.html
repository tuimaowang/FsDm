GetCpuUsage

测试当前设备全部逻辑处理器的平均忙碌时间百分比，包含整台电脑上各进程的 CPU 工作量。可在未绑定窗口的状态下调用。

函数声明

double WINAPI GetCpuUsage(void);

参数与返回值

无参数。成功返回 0～100 的小数，例如 23.56 表示 23.56%。失败返回 -1，可立即调用 Windows 的 GetLastError 获取系统或 PDH 错误码。PDH 是 Windows 提供的性能计数器接口。

采样方式

每次同步采集两次计数器数据，中间等待约 200 毫秒，返回该时间窗口的平均占用率。实际调用耗时还包含计数器初始化和系统调度开销。忙碌时间按全部逻辑处理器归一化，包括多处理器组设备。

各次调用、各线程拥有独立采样数据。调用线程会等待采样结束，适合在独立的监测线程中配合持续运行的 OCR、找图或 YOLO 观察负载。单次 OCR 完成后再调用，本次采样覆盖随后约 200 毫秒。

工作台完整调用实例

// 加载 ZhaoTu.dll 后逐行输入，每次显示小数返回值和耗时。
GetCpuUsage()
GetGpuUsage()
GetCpuUsage()

C++ 完整调用实例

// 配置 ZhaoTu.h 的包含目录，链接 ZhaoTu.lib，运行时加载配套 ZhaoTu.dll。
#include "ZhaoTu.h"
#include <cstdio>

int main() {
    for (int i = 0; i < 5; ++i) {
        const double cpu = GetCpuUsage();
        const DWORD error = GetLastError();
        if (cpu < 0.0) {
            std::printf("GetCpuUsage failed, error=0x%08lX\n", error);
            return 1;
        }
        std::printf("CPU %.2f%%\n", cpu);
        Sleep(800);
    }
    return 0;
}
