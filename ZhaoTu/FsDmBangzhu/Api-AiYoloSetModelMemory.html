AiYoloSetModelMemory

函数简介

复制调用方内存中的完整 ONNX 文件字节，建立 CPU 推理会话并登记模型。

函数原型

int WINAPI AiYoloSetModelMemory(int index, uintptr_t data, int size, const char* password);

参数定义

参数含义
index模型编号，整数 0～19。
data当前进程中完整、未加密 ONNX 字节的起始地址。必须非零，并在本次调用期间可读取 size 个字节。
size字节数量，大于 0 且不超过 512 MiB。
password传入空字符串 ""。

返回值与结果处理

  • 1 表示复制、校验及登记成功，函数返回后可释放调用方原始模型字节。
  • 0 表示失败，立即在同线程调用 GetOcrError() 读取原因。

作用范围与调用说明

  • 模型表、版本设置和当前选中编号在当前进程的这一个 ZhaoTu.dll 实例内跨线程共享。多个线程共用当前模型选择，已经取得模型引用的检测可继续使用该次取得的模型。
  • 内存版自动使用类别编号的十进制字符串作为类别名，例如 "0"、"1"。该入口仅接收模型字节，类别名由模型输出类别数生成。
  • 同编号加载成功会替换原模型，加载失败保留原模型。检测使用前调用 AiYoloUseModel。
  • 工作台可以接收数值地址，该地址必须指向工作台所在进程内的有效内存。下方 C++ 示例负责读取文件并传入真实地址。

完整 C++ 调用示例

路径使用本项目 Release 目录附带的 FP32 模型，按实际文件位置和窗口区域调整。本例独占绑定和全量结果释放时机，调用方须在目标窗口所属进程中运行。

#include "FsDmJiekou.h"
#include <cstdio>
#include <fstream>
#include <vector>

// 在目标窗口所属进程调用，hwnd 为实际窗口句柄。
// 包含 FsDmJiekou.h，链接 ZhaoTu.lib，并部署配套 DLL 与模型。
bool CeshiAiYoloSetModelMemory(HWND hwnd) {
    std::ifstream input(R"(C:\Users\Administrator\Documents\DaMo\FsDm\out\build\bin\Release\YoloMoxing\yolov5n.onnx)", std::ios::binary | std::ios::ate);
    if (!input) return false;
    const auto length = input.tellg();
    if (length <= 0 || length > 512LL * 1024 * 1024) return false;
    std::vector<unsigned char> modelBytes(static_cast<size_t>(length));
    input.seekg(0);
    if (!input.read(reinterpret_cast<char*>(modelBytes.data()),
                    static_cast<std::streamsize>(modelBytes.size()))) return false;
    if (!AiYoloSetVersion("v5-7.0")) return false;
    if (!AiYoloSetModelMemory(0, reinterpret_cast<uintptr_t>(modelBytes.data()),
                              static_cast<int>(modelBytes.size()), "")) {
        std::printf("%s\n", GetOcrError());
        FreeAllStringResults();
        return false;
    }
    // 模型字节已复制，可在此释放 modelBytes，类别名为数字字符串。
    if (!AiYoloUseModel(0)) {
        AiYoloFreeModel(0);
        return false;
    }
    if (!BindWindow(hwnd, "dx", "normal", "normal", 0)) {
        AiYoloFreeModel(0);
        return false;
    }
    // 绑定成功后等待首张可用快照，最多约一秒。
    bool ready = false;
    for (int attempt = 0; attempt < 100; ++attempt) {
        FsZhuangtai state{};
        state.size = sizeof(state);
        if (GetStatus(&state) == FS_CHENGGONG && state.result == FS_CHENGGONG
            && state.bound && state.hasFrame) {
            ready = true;
            break;
        }
        Sleep(10);
    }
    bool ok = false;
    if (ready) {
        const char* objects = AiYoloDetectObjects(0, 0, 834, 419, 0.5, 0.45);
        // 立即读取本线程检测诊断，避免后续调用覆盖诊断。
        const char* error = GetOcrError();
        if (objects && error && *error == '\0') {
            std::printf("objects=%s\n", objects);
            ok = true;
        } else {
            std::printf("%s\n", error ? error : "结果内存分配失败");
        }
    }
    // 本例全部结果读取结束后统一释放。
    FreeAllStringResults();
    UnBindWindow();
    const bool freed = AiYoloFreeModel(0) == 1;
    return ok && freed;
}
