UseOcrModel

函数简介：

选择后续模型 OCR 使用的模型编号。此设置在当前进程的 ZhaoTu.dll 实例内全局共享。

函数原型：


int WINAPI UseOcrModel(int index);

参数定义：

  • index：已登记的模型编号，0～99。

返回值：

  • 1：选择成功。
  • 0：编号无效、未登记或默认模型登记失败。

示例：


UseOcrModel(0)

作用范围

UseOcrModel(index) 修改的是当前进程中这一个 ZhaoTu.dll 实例共享的模型编号，不是每个线程各自独立的设置，也不是整台计算机的系统级设置。任一线程调用后，所有线程随后开始的 model 引擎 OCR 都使用新选择的模型；已经开始的识别沿用该次调用开始时取得的设置。多个线程若需要不同模型，不应并发切换后再依赖各自独立选择。

此函数只选择已登记的模型，不负责登记模型或选择 OCR 引擎。默认模型编号为 0，资源来自 ZhaoTu.dll 同目录的 ocr_models；要使用其他模型，先调用 SetOcrModel 或 SetOcrModelFiles。如果当前引擎为 dict，调用本函数不会自动切换引擎，需另行调用 SetOcrEngine("model")。

完整 OCR 调用示例

以下示例使用 models10 英文模型。请把路径和 hwnd 替换为本机模型文件与目标窗口句柄。窗口 OCR 前须成功绑定；若此前已经绑定，可省略 BindWindow。

SetOcrModelFiles(1,
    "C:\\Users\\Administrator\\Documents\\DaMo\\ocr_model\\models10\\cls.onnx",
    "C:\\Users\\Administrator\\Documents\\DaMo\\ocr_model\\models10\\detEN.onnx",
    "C:\\Users\\Administrator\\Documents\\DaMo\\ocr_model\\models10\\RecEN.onnx",
    "C:\\Users\\Administrator\\Documents\\DaMo\\ocr_model\\models10\\KeysEN.txt");
UseOcrModel(1);
SetOcrEngine("model");
SetOcrBackend("cpu");
BindWindow(hwnd, "dx", "normal", "normal", 0);

const FsTongyongJieguo* result = OcrEx(0, 0, 834, 419, "", 0.5);
if (result != nullptr) {
    if (result->status == FS_CHENGGONG) {
        const char* fullText = result->fullText;
        for (uint32_t i = 0; i < result->count; ++i) {
            const FsJieguoXiang& item = result->items[i];
            // item.text 为 UTF-8 单字符，item.x/item.y 为字符位置。
        }
        // 在此处理 fullText 和字符条目。
    }
    FreeResult(result);
}

调用顺序： 先登记模型，再选择模型、设置 model 引擎和推理后端；绑定窗口后调用 OcrEx。检查 status 后读取 fullText 或 items，读取完成再调用 FreeResult；释放后不能继续访问结果及其内部指针。

完整调用实例：请参阅UseOcrModel 所属工作流，其中包含前置设置、调用及结果/资源处理。
