返回结果与错误判断

四个 FindPic 函数都返回 const FsTongyongJieguo*。结果对象和其内部数组由 DLL 分配；调用方只能读取，不能自行 delete 或 free。

三个必须区分的状态

返回情况含义调用方处理
结果指针为 nullptrDLL 无法分配结果对象。不能读取字段；记录本次失败。
r->status == FS_CHENGGONG 且 count == 0查找正常完成，但没有匹配。这是正常未命中，不是接口错误。
r->status != FS_CHENGGONG参数、绑定、采集、模板加载等执行失败。记录 status 和 detail；不要把它当作无匹配。
r->status == FS_CHENGGONG 且 count > 0查找成功并命中。仅遍历 [0, count) 内的条目。

找图条目

每项 FsJieguoXiang 的有效字段为 FS_JG_ID | FS_JG_XY | FS_JG_FILE：

  • id：模板在输入列表中的从零开始索引。第一张模板的 id 是 0，不代表失败。
  • x, y：命中模板左上角的客户区物理像素位置。
  • file：命中模板名称，以 UTF-8 字符串读取。
  • fields：字段有效标志；用按位检查判断字段是否有效。

FsTongyongJieguo 还包含 size、version、status、detail、count、items 和 fullText。找图不使用全文字段。

所有结果结构、字段有效标志及其他找图诊断结构的字段说明，见结构体目录。

释放结果

const FsTongyongJieguo* r = FindPic(...);
if (r != nullptr) {
    // 必须先读取并处理 r 及 r->items。
    FreeResult(r);
    r = nullptr;
}

FreeResult 只释放传入的这一项结果及其条目、字符串；空指针成功，未知地址或重复释放返回 0。释放后，r、items 和条目中的文字指针全部失效。

如果要全量释放所有线程未释放的通用识别结果，可以调用 FreeAllResults()。全量释放前必须确保没有线程仍在读取这些结果。找图模板另由 FreePic 管理，两类资源不能混淆。

常见 status

状态码常量常见原因
0FS_CHENGGONG调用正常；继续查看 count 判断命中与否。
1FS_WEIBANGDING没有绑定窗口或绑定已失效。
2FS_DENGDAISHOUZHEN绑定已完成，但还没有第一帧。

8FS_CAIJI_SHIBAI采集或像素读取失败。
9FS_JIAZAI_SHIBAI所有模板均不可加载，或 BMP 内容无效。
12FS_ZIYUAN_MANG缓存、GPU 或候选等资源暂时不足。
完整状态定义见 Gonggong\Jiekou.h 中的 enum FsJieguo。detail 是补充诊断值；只有在相应失败状态下才结合它定位底层原因。
