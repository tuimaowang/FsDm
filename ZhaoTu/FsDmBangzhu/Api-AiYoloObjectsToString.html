AiYoloObjectsToString

函数简介

把检测字符串中的类别编号映射为当前选中模型的类别名，返回以 | 分隔的名称列表。

函数原型

const char* WINAPI AiYoloObjectsToString(const char* objects);

参数定义

参数含义
objects检测结果字符串，例如 "0,0.920000,100,80,60,120|2,0.850000,220,90,80,50"。应与当前选中模型的类别表对应。

返回值与结果处理

  • 成功示例为 "person|car"，名称顺序与输入目标顺序一致，重复类别会重复输出。返回内容为类别名列表。
  • 文件模型的名称来自同名 .class，内存模型的名称为数字字符串，例如 "0|2"。
  • 空列表或转换失败返回空字符串，分配失败可能返回 nullptr。此函数捕获异常后没有更新 GetOcrError 的诊断信息。
  • 返回值为 DLL 分配的独立 UTF-8 字符串，分配失败可能返回 nullptr。使用完后调用 FreeAllStringResults() 或 FreeAllResults()。全量释放会同时回收其他线程持有的字符串和通用结果，调用前须完成所有结果读取。工作台会自动显示并释放本次字符串结果。

作用范围与调用说明

  • 模型表、版本设置和当前选中编号在当前进程的这一个 ZhaoTu.dll 实例内跨线程共享。多个线程共用当前模型选择，已经取得模型引用的检测可继续使用该次取得的模型。
  • 转换时通过当前模型类别表查找类别编号。加载其他模型、切换编号或释放当前模型可能影响转换结果，应在对应模型仍被选中时完成转换。
  • 坐标和置信度可继续从原检测字符串读取，转换结果用于取得名称。

完整 C++ 调用示例

路径使用本项目 Release 目录附带的 FP32 模型，按实际文件位置和窗口区域调整。本例独占绑定和全量结果释放时机，调用方须在目标窗口所属进程中运行。

#include "FsDmJiekou.h"
#include <cstdio>

// 在目标窗口所属进程调用，hwnd 为实际窗口句柄。
// 包含 FsDmJiekou.h，链接 ZhaoTu.lib，并部署配套 DLL 与模型。
bool CeshiAiYoloObjectsToString(HWND hwnd) {
    if (!AiYoloSetVersion("v5-7.0")) return false;
    if (!AiYoloSetModel(0, R"(C:\Users\Administrator\Documents\DaMo\FsDm\out\build\bin\Release\YoloMoxing\yolov5n.onnx)", "")) {
        std::printf("%s\n", GetOcrError());
        FreeAllStringResults();
        return false;
    }
    if (!AiYoloUseModel(0)) {
        AiYoloFreeModel(0);
        return false;
    }
    if (!BindWindow(hwnd, "dx", "normal", "normal", 0)) {
        AiYoloFreeModel(0);
        return false;
    }
    // 绑定成功后等待首张可用快照，最多约一秒。
    bool ready = false;
    for (int attempt = 0; attempt < 100; ++attempt) {
        FsZhuangtai state{};
        state.size = sizeof(state);
        if (GetStatus(&state) == FS_CHENGGONG && state.result == FS_CHENGGONG
            && state.bound && state.hasFrame) {
            ready = true;
            break;
        }
        Sleep(10);
    }
    bool ok = false;
    if (ready) {
        const char* objects = AiYoloDetectObjects(0, 0, 834, 419, 0.5, 0.45);
        // 立即读取本线程检测诊断，避免后续调用覆盖诊断。
        const char* error = GetOcrError();
        if (objects && error && *error == '\0') {
            const char* names = AiYoloObjectsToString(objects);
            if (names) {
                std::printf("names=%s\n", names);
                ok = (*objects == '\0') || (*names != '\0');
            }
        } else {
            std::printf("%s\n", error ? error : "结果内存分配失败");
        }
    }
    // 本例全部结果读取结束后统一释放。
    FreeAllStringResults();
    UnBindWindow();
    const bool freed = AiYoloFreeModel(0) == 1;
    return ok && freed;
}
