const FsTongyongJieguo* WINAPI FindPicExS(
    int x1, int y1, int x2, int y2,
    const char* pic_name, const char* delta_color,

函数结果数量用途
FindPic0 或 1返回输入模板列表中优先模板的第一个命中。
FindPicS0 或 1与 FindPic 使用相同结果结构，保留名称以兼容旧调用代码。
FindPicEx0～1500返回全部命中；先返回第一张模板的命中，再处理下一张。
FindPicExS0～1500与 FindPicEx 使用相同结果结构，保留名称以兼容旧调用代码。

参数

参数说明
x1, y1查找区域左上角。
x2, y2查找区域右下边界，不包含该边界。窗口查找采用客户区物理像素坐标。
pic_name一个或多个 BMP24、PNG 或 JPG/JPEG 文件名，以 | 分隔；可使用文件路径或已由 LoadPicByte 加载的内存模板别名。列表索引从 0 开始。
delta_color六位十六进制 RGB 通道偏色容差，例如 "203040"；"000000" 表示不增加额外容差。
sim合法范围为 0.1～1.0。它不是命中像素百分比；特定离散值增加各 RGB 通道容差。
dir扫描方向，找图只支持 0～3。

相似度与容差

BMP24 四角同色的模板像素按透明色忽略；整张模板同色时例外，按不透明图比较。PNG 的完全透明像素跳过，半透明像素按解码后的 RGB 比较；JPG/JPEG 按不透明图处理。模板尺寸不会自动缩放。匹配时对所有有效、非透明模板像素逐通道比较。sim 的离散附加容差如下，容差与 delta_color 相加：

sim每个 RGB 通道附加容差
0.549
0.638
0.729
0.818
0.99
其他合法值（含 1.0）0

扫描方向

dir起始角与扫描顺序
0从左到右、从上到下。
1从左到右、从下到上。
2从右到左、从上到下。
3从右到左、从下到上。

返回值与资源

返回独立的 FsTongyongJieguo。先判断指针是否为空，再检查 status；仅当 status == FS_CHENGGONG 时，count == 0 才表示正常无命中。命中条目提供模板列表索引 id、模板左上角坐标 x/y 和模板名称 file。用完必须调用 FreeResult(result)，不得直接释放结构或其内部指针。详见结果说明。

FindPic 示例

FindPic(0, 0, 834, 419, "test.bmp|test1.bmp", "000000", 0.9, 0)

按模板列表顺序优先；每项无法加载时跳过并保留原索引。若所有模板都无法加载，状态为 FS_JIAZAI_SHIBAI（9）。找到有效模板但没有命中则是 status=0, count=0。

FindPicS

FindPicS(0, 0, 834, 419, "test.bmp|test1.bmp", "000000", 0.9, 0)

返回规则和字段布局与 FindPic 相同；每个结果仍用 items[i].id/x/y/file 读取。

FindPicEx

FindPicEx(0, 0, 834, 419, "test.bmp|test1.bmp", "000000", 0.9, 0)

最多返回 1500 项。按输入模板顺序依次列出每张模板的所有命中；保留重叠位置以及不同模板产生的重复位置。

FindPicExS

FindPicExS(0, 0, 834, 419, "test.bmp|test1.bmp", "000000", 0.9, 0)

与 FindPicEx 一样返回最多 1500 个匹配条目；每项包含 id、x、y、file。
