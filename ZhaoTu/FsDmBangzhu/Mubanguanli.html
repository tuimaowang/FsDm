模板管理函数

LoadPic

函数简介

预先加载 BMP24、PNG、JPG/JPEG 图片模板，供后续找图使用。

函数原型

int WINAPI LoadPic(const char* pic_name);

参数定义

  • pic_name：模板文件名；多个名称用 | 分隔，文件名支持 * 和 ? 通配符。

返回值

整型数：1 表示全部加载成功，0 表示至少一个模板加载失败。

示例

LoadPic("button.bmp|close.bmp")
LoadPic("menu*.bmp")

LoadPicByte

函数简介

从当前进程内存中的 BMP24 文件数据加载图片模板。

函数原型

int WINAPI LoadPicByte(uintptr_t addr, int size, const char* pic_name);

参数定义

  • addr：当前进程内完整 BMP 文件数据的首地址。
  • size：BMP 文件总字节数，包含文件头。
  • pic_name：该内存模板的名称，供找图函数传入。

返回值

整型数：1 表示加载成功，0 表示地址、文件内容或大小无效。

示例

LoadPicByte(0x实际BMP内存地址, 实际文件字节数, "memory.bmp")

FreePic

函数简介

释放已缓存的图片模板。

函数原型

int WINAPI FreePic(const char* pic_name);

参数定义

  • pic_name：模板文件名；多个名称用 | 分隔，支持 * 和 ? 通配符。

返回值

整型数：1 表示释放完成，0 表示参数无效或释放失败。

示例

FreePic("button.bmp|memory.bmp")

MatchPicName

函数简介

按名称和通配符查找 SetPath 目录中的 BMP、PNG、JPG/JPEG 文件。

函数原型

const char* WINAPI MatchPicName(const char* pic_name);

参数定义

  • pic_name：图片文件名列表；多个名称用 | 分隔，文件名支持 * 和 ? 通配符。

返回值

以 | 分隔的匹配文件名字符串；没有匹配项或发生错误时返回空字符串。返回字符串使用完后调用 FreeAllResults 释放。

示例

MatchPicName("button*.bmp|icon*.png|close*.jpg")

FreeAllResults

函数简介

释放当前 DLL 返回、尚未释放的查找结果和独立字符串。

函数原型

int WINAPI FreeAllResults(void);

参数定义

无。

返回值

整型数：1 表示释放成功，0 表示失败。

示例

FreeAllResults()
