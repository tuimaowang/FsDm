AiYoloUseModel

函数简介

选择后续 YOLO 检测和类别名称转换使用的模型编号。

函数原型

int WINAPI AiYoloUseModel(int index);

参数定义

参数含义
index已通过文件版或内存版成功登记的模型编号，0～19。

返回值与结果处理

  • 1 表示选择成功。
  • 0 表示编号越界或该编号尚未加载模型。此函数失败时没有更新 GetOcrError 的诊断信息。

作用范围与调用说明

  • 模型表、版本设置和当前选中编号在当前进程的这一个 ZhaoTu.dll 实例内跨线程共享。多个线程共用当前模型选择，已经取得模型引用的检测可继续使用该次取得的模型。
  • 当前选择编号初始为 0，使用其他编号时应显式选择。模型登记和模型选择分别通过 SetModel 与 UseModel 完成。
  • AiYoloObjectsToString 使用调用时选中的模型类别表，处理已有检测字符串时应保持对应模型被选中。

完整 C++ 调用示例

路径使用本项目 Release 目录附带的 FP32 模型，按实际文件位置和窗口区域调整。本例独占绑定和全量结果释放时机，调用方须在目标窗口所属进程中运行。

#include "FsDmJiekou.h"
#include <cstdio>

// 在目标窗口所属进程调用，hwnd 为实际窗口句柄。
// 包含 FsDmJiekou.h，链接 ZhaoTu.lib，并部署配套 DLL 与模型。
bool CeshiAiYoloUseModel(HWND hwnd) {
    if (!AiYoloSetVersion("v5-7.0")) return false;
    if (!AiYoloSetModel(0, R"(C:\Users\Administrator\Documents\DaMo\FsDm\out\build\bin\Release\YoloMoxing\yolov5n.onnx)", "")) {
        std::printf("%s\n", GetOcrError());
        FreeAllStringResults();
        return false;
    }
    if (!AiYoloUseModel(0)) {
        AiYoloFreeModel(0);
        return false;
    }
    if (!BindWindow(hwnd, "dx", "normal", "normal", 0)) {
        AiYoloFreeModel(0);
        return false;
    }
    // 绑定成功后等待首张可用快照，最多约一秒。
    bool ready = false;
    for (int attempt = 0; attempt < 100; ++attempt) {
        FsZhuangtai state{};
        state.size = sizeof(state);
        if (GetStatus(&state) == FS_CHENGGONG && state.result == FS_CHENGGONG
            && state.bound && state.hasFrame) {
            ready = true;
            break;
        }
        Sleep(10);
    }
    bool ok = false;
    if (ready) {
        const char* objects = AiYoloDetectObjects(0, 0, 834, 419, 0.5, 0.45);
        // 立即读取本线程检测诊断，避免后续调用覆盖诊断。
        const char* error = GetOcrError();
        if (objects && error && *error == '\0') {
            std::printf("objects=%s\n", objects);
            ok = true;
        } else {
            std::printf("%s\n", error ? error : "结果内存分配失败");
        }
    }
    // 本例全部结果读取结束后统一释放。
    FreeAllStringResults();
    UnBindWindow();
    const bool freed = AiYoloFreeModel(0) == 1;
    return ok && freed;
}
