FsDm 找图接口帮助

本帮助介绍 ZhaoTu.dll 导出的图片查找函数：FindPic、FindPicS、FindPicEx 和 FindPicExS，支持 BMP24、PNG、JPG/JPEG 文件模板，以及调用它们所需的路径、模板和结果管理接口。

最快调用流程

  1. 加载 ZhaoTu.dll，并从同一 DLL 取得查找与释放函数。
  2. 窗口找图前，先用 BindWindow 绑定调用进程自己的窗口，并确认已有首帧。
  3. 用 SetPath 指定图片模板所在目录；也可以传模板绝对路径。
  4. 调用 FindPic 查找第一个位置，或调用 FindPicEx 查找全部位置。
  5. 先检查返回指针和 status，再按 count 遍历 items。
  6. 读取完成后调用 FreeResult 释放这一次的结果。

各函数对应的端到端示例（包括必要设置、调用、读取结果与释放资源）见完整调用实例。

const FsTongyongJieguo* r =
    FindPic(0, 0, 1280, 720, "button.bmp", "000000", 0.9, 0);
if (r != nullptr) {
    if (r->status == FS_CHENGGONG && r->count > 0) {
        const FsJieguoXiang& hit = r->items[0];
        // hit.x、hit.y 是模板左上角的客户区物理像素坐标
    }
    FreeResult(r);
}

OpenCV 模板匹配提供 CvFindPic 系列接口；AI 图像接口说明 YOLO 目标检测函数。

路径与字符串约定

SetPath(const char* path) 设置相对模板路径的基础目录。字符串参数采用 UTF-8；Windows 路径请在 C++ 中使用双反斜杠或原始字符串。绝对路径不受 SetPath 影响。

SetPath("C:\\Users\\Administrator\\Documents\\DaMo\\FsDm");
// 或：SetPath(R"(C:\Users\Administrator\Documents\DaMo\FsDm)");

区域坐标是客户区物理像素；找图区域的右下边界不包含在内。窗口外部截图或查找前应按实际窗口尺寸填写区域。

选择 CPU 或 GPU

SetFindBackend("cpu") 或 SetFindBackend("gpu") 选择找图执行方式，默认是 GPU。此设置可以在绑定期间更改，不会重启采集；GPU 不可用时不会自动退回 CPU。该选择与窗口采集方式独立。

本帮助只说明找图接口。采集后端、找色、OCR 等完整接口请查看项目中的《函数使用说明》。实际 C/C++ 声明以 ZhaoTu\ZhaoTu.h 和交付头文件为准。
