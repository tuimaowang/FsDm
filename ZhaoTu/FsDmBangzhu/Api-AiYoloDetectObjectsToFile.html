AiYoloDetectObjectsToFile

函数简介

检测窗口区域，并将该区域及红色检测框标注保存为 BMP 文件。

函数原型

int WINAPI AiYoloDetectObjectsToFile(int x1, int y1, int x2, int y2, double prob, double iou, const char* file, int mode);

参数定义

参数含义
x1、y1检测区域左上角，单位为目标窗口客户区物理像素。超出左上边界的部分会裁剪。
x2、y2检测区域右下角，右边界和下边界不包含。须满足 x2>x1、y2>y1，超出客户区的部分会裁剪，裁剪后区域须非空。
prob置信度阈值，有限数值 0～1，例如 0.5。置信度由目标存在分数乘以最高类别分数得到，低于阈值的候选框被过滤。提高阈值通常减少返回数量。
iou同类别重叠框过滤阈值，有限数值 0～1，例如 0.45。IoU 是两框交集面积除以并集面积。按置信度从高到低保留框，与已保留同类框的 IoU 大于阈值时删除该候选框。降低阈值会更积极地过滤重叠框。
fileUTF-8 输出路径，绝对路径直接使用，相对路径按 SetPath 解析，未设置时按进程当前目录解析。父目录须已存在，同名文件会被覆盖。文件内容为 24 位 BMP。
mode0 表示标注类别编号和置信度，1 表示仅标注类别编号。

返回值与结果处理

  • 1 表示检测及文件写入成功。没有目标时也保存区域图片并返回 1。
  • 0 表示失败，立即在同线程调用 GetOcrError() 读取原因。

作用范围与调用说明

  • 调用前成功绑定目标窗口、等待首帧，并调用 AiYoloSetVersion、AiYoloSetModel（或内存版）、AiYoloUseModel。当前 ONNX 推理、预处理和重叠框过滤均在 CPU 执行。
  • 区域先从共享的完整采集帧中裁剪，再按比例缩放并补边为 640×640，转换为 RGB 浮点输入。结果坐标映射回客户区，包含检测区域的 x1、y1 偏移。
  • 三个检测入口共用检测结果缓存，缓存保存已经算出的检测框和对应区域图像。同一绑定、同一帧、同一模型及相同区域、prob、iou 且缓存仍保留时，复用结果并跳过取图、预处理和模型推理。
  • SetFrameResultCache(0) 允许复用结果，为默认行为。SetFrameResultCache(1) 强制每次执行分析。此开关在 DLL 内全局共享，同帧像素仍可由帧缓存复用。缓存有容量限制，被淘汰的结果会重新计算。
  • SetCaptureFrameInterval(-1) 固定已发布的采集快照，SetCaptureFrameInterval(0) 恢复无间隔采集。固定帧和复用结果分别由采集设置和结果缓存开关控制。
  • 保存图片的内容为裁剪后的检测区域，尺寸为该区域映射到采集帧后的像素尺寸。复用检测结果时仍执行绘制、编码和文件写入。

完整 C++ 调用示例

路径使用本项目 Release 目录附带的 FP32 模型，按实际文件位置和窗口区域调整。本例独占绑定和全量结果释放时机，调用方须在目标窗口所属进程中运行。

#include "FsDmJiekou.h"
#include <cstdio>

// 在目标窗口所属进程调用，hwnd 为实际窗口句柄。
// 包含 FsDmJiekou.h，链接 ZhaoTu.lib，并部署配套 DLL 与模型。
bool CeshiAiYoloDetectObjectsToFile(HWND hwnd) {
    if (!AiYoloSetVersion("v5-7.0")) return false;
    if (!AiYoloSetModel(0, R"(C:\Users\Administrator\Documents\DaMo\FsDm\out\build\bin\Release\YoloMoxing\yolov5n.onnx)", "")) {
        std::printf("%s\n", GetOcrError());
        FreeAllStringResults();
        return false;
    }
    if (!AiYoloUseModel(0)) {
        AiYoloFreeModel(0);
        return false;
    }
    if (!BindWindow(hwnd, "dx", "normal", "normal", 0)) {
        AiYoloFreeModel(0);
        return false;
    }
    // 绑定成功后等待首张可用快照，最多约一秒。
    bool ready = false;
    for (int attempt = 0; attempt < 100; ++attempt) {
        FsZhuangtai state{};
        state.size = sizeof(state);
        if (GetStatus(&state) == FS_CHENGGONG && state.result == FS_CHENGGONG
            && state.bound && state.hasFrame) {
            ready = true;
            break;
        }
        Sleep(10);
    }
    bool ok = false;
    if (ready) {
        ok = AiYoloDetectObjectsToFile(0, 0, 834, 419, 0.5, 0.45,
                    R"(C:\Users\Administrator\Documents\DaMo\FsDm\yolo_result.bmp)", 0) == 1;
        if (!ok) std::printf("%s\n", GetOcrError());
    }
    // 本例全部结果读取结束后统一释放。
    FreeAllStringResults();
    UnBindWindow();
    const bool freed = AiYoloFreeModel(0) == 1;
    return ok && freed;
}
