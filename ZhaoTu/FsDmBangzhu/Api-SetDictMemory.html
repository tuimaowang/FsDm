SetDictMemory

函数简介：

从当前进程的内存数据加载 TSPlug 未加密文本点阵字库，并将其设为当前字库。该字库供 dict 引擎下的 Ocr、OcrEx 和 FindStr 系列函数使用。

函数原型：

int WINAPI SetDictMemory(int index, uintptr_t address, int size);

参数定义：

  • index：字库编号，范围 0～99。
  • address：当前进程可读内存中，完整字库文本数据的首地址。C++ 使用 reinterpret_cast<uintptr_t>(data) 传入，工作台可传十进制地址。
  • size：字库数据字节数，范围为 1 字节～16 MiB。支持 UTF-8（含 BOM）或 GB18030 编码。

返回值：1 表示成功加载并选中该编号；0 表示参数、内存地址、字库编码或格式无效。失败时保留该编号之前已加载的字库。

内存与格式：函数会先把调用方指定的字节复制到 DLL 自己的内存，再校验和解析字库；成功返回后，调用方可立即释放或修改原缓冲区。地址必须属于当前进程且在调用期间保持可读。仅支持未加密的 TSPlug 十六进制点阵文本，不支持大漠加密字库，也不支持 SetOcrModelFiles 所使用的神经网络字符表。

C++ 示例：

#include <cstdint>
#include <fstream>
#include <iterator>
#include <string>
#include <vector>

std::ifstream input("ziku.txt", std::ios::binary);
std::vector<char> bytes((std::istreambuf_iterator<char>(input)), {});
if (!bytes.empty()) {
    // DLL 会复制数据，因此 SetDictMemory 返回后 bytes 可释放。
    if (SetDictMemory(0, reinterpret_cast<uintptr_t>(bytes.data()),
                      static_cast<int>(bytes.size())) == 1) {
        SetOcrEngine("dict");
        // 之后可调用 OcrEx(...) 或 FindStr*(...)。
    }
}

工作台示例：先在调用程序中准备好字库缓冲区，再将实际内存地址和字节长度传入，例如 SetDictMemory(0, 12345678, 1200)。不要把示例数字当作真实地址。

完整调用实例：请参阅点阵字库 OCR 与找字工作流。
