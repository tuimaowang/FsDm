SetOcrModel

函数简介：

登记一个 OCR 模型目录并校验必要资源。

函数原型：


int WINAPI SetOcrModel(int index, const char* model_dir);

参数定义：

  • index：模型编号，0～99。
  • model_dir：UTF-8 模型目录；支持项目默认 PP-OCRv5 mobile，以及 PP-OCRv3 中文 models 或 models10 文件布局。

返回值：

  • 1：登记成功。
  • 0：编号、路径、配置或模型资源无效。

示例：


SetOcrModel(1, "C:\模型目录")

注意： PP-OCRv3 当前使用中文识别模型和方向分类模型，英文专用识别模型不参与推理。登记不自动选中，随后 UseOcrModel(1)。实际推理会话在首次识别时创建；相同规范目录重复登记复用会话。不是任意 ONNX 模型都兼容。

完整调用实例：请参阅SetOcrModel 所属工作流，其中包含前置设置、调用及结果/资源处理。
