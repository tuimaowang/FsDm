FsZhuangtai

FsZhuangtai 是 GetStatus 通过参数返回的状态结构，用于查询绑定状态、最近采集诊断及最新帧信息。结构大小为 208 字节。

FsZhuangtai status{};
status.size = sizeof(status);
int ret = GetStatus(&status);
字段含义
size调用前填写结构字节数。
version结构布局版本；当前为 1。
result当前采集状态，取 FsJieguo。GetStatus 返回 0 只表示查询成功，具体状态看此字段。
detail原始 HRESULT 或 Win32 错误等补充诊断值。
bound是否存在有效绑定。
hasFrame是否缓存画面；是否可读取仍需检查 result。
initializing底层拦截或采集是否仍在初始化。
inputImplemented键鼠输入是否已实现，当前为 0。
hwnd绑定窗口句柄的完整 x64 数值。
bindingVersion当前绑定版本。
capturedFrames、failedFrames本次绑定成功发布的快照数、采集失败数；解绑时清零。
ownerThreadId发起绑定的线程 ID；线程退出后自动解绑。
mode绑定时保存的模式值 0 或 1。
display采集显示方式：dx、obs 或 wgc。
mouse、keypad绑定时保存的鼠标、键盘配置；当前只保存，不执行键鼠操作。
frame最新成功发布帧的信息；hasFrame=0 时不可视为有效画面。

相关函数：GetStatus。
