AiYoloSetModel

函数简介

从 ONNX 文件加载并校验模型，建立 CPU 推理会话，将模型登记到指定编号。

函数原型

int WINAPI AiYoloSetModel(int index, const char* file, const char* password);

参数定义

参数含义
index模型编号，整数 0～19。
fileUTF-8 ONNX 文件路径，扩展名为 .onnx。绝对路径直接使用，相对路径按 SetPath 设置的目录解析，未设置时按进程当前目录解析。文件大小大于 0 且不超过 512 MiB。同目录须放置同名 .class 文件，例如 yolov5n.onnx 和 yolov5n.class。
password传入空字符串 ""。

返回值与结果处理

  • 1 表示文件、类别表及推理会话校验成功，并登记到指定编号。
  • 0 表示失败，立即在同线程调用 GetOcrError() 可读取原因。

作用范围与调用说明

  • 模型表、版本设置和当前选中编号在当前进程的这一个 ZhaoTu.dll 实例内跨线程共享。多个线程共用当前模型选择，已经取得模型引用的检测可继续使用该次取得的模型。
  • 类别文件使用 UTF-8，每个非空行对应一个类别名，首行编号为 0。行首尾空白会去除，空行忽略，类别数量须与模型输出一致。
  • 同编号加载成功会替换原模型，加载失败保留原模型。设置模型保持当前选择编号，使用前通过 AiYoloUseModel 明确选择。
  • 此函数会创建模型会话，首次加载耗时可能较高。推理依赖 ZhaoTu.dll 同目录中配套的 onnxruntime.dll。

完整 C++ 调用示例

路径使用本项目 Release 目录附带的 FP32 模型，按实际文件位置和窗口区域调整。本例独占绑定和全量结果释放时机，调用方须在目标窗口所属进程中运行。

#include "FsDmJiekou.h"
#include <cstdio>

// 在目标窗口所属进程调用，hwnd 为实际窗口句柄。
// 包含 FsDmJiekou.h，链接 ZhaoTu.lib，并部署配套 DLL 与模型。
bool CeshiAiYoloSetModel(HWND hwnd) {
    if (!AiYoloSetVersion("v5-7.0")) return false;
    if (!AiYoloSetModel(0, R"(C:\Users\Administrator\Documents\DaMo\FsDm\out\build\bin\Release\YoloMoxing\yolov5n.onnx)", "")) {
        std::printf("%s\n", GetOcrError());
        FreeAllStringResults();
        return false;
    }
    if (!AiYoloUseModel(0)) {
        AiYoloFreeModel(0);
        return false;
    }
    if (!BindWindow(hwnd, "dx", "normal", "normal", 0)) {
        AiYoloFreeModel(0);
        return false;
    }
    // 绑定成功后等待首张可用快照，最多约一秒。
    bool ready = false;
    for (int attempt = 0; attempt < 100; ++attempt) {
        FsZhuangtai state{};
        state.size = sizeof(state);
        if (GetStatus(&state) == FS_CHENGGONG && state.result == FS_CHENGGONG
            && state.bound && state.hasFrame) {
            ready = true;
            break;
        }
        Sleep(10);
    }
    bool ok = false;
    if (ready) {
        const char* objects = AiYoloDetectObjects(0, 0, 834, 419, 0.5, 0.45);
        // 立即读取本线程检测诊断，避免后续调用覆盖诊断。
        const char* error = GetOcrError();
        if (objects && error && *error == '\0') {
            std::printf("objects=%s\n", objects);
            ok = true;
        } else {
            std::printf("%s\n", error ? error : "结果内存分配失败");
        }
    }
    // 本例全部结果读取结束后统一释放。
    FreeAllStringResults();
    UnBindWindow();
    const bool freed = AiYoloFreeModel(0) == 1;
    return ok && freed;
}
