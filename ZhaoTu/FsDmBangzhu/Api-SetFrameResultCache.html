SetFrameResultCache

函数简介：

全局设置是否复用同一采集帧上的识别结果。适用于 OCR、YOLO 及已接入该开关的其他识别入口。默认开启结果复用。

函数原型：

int WINAPI SetFrameResultCache(int bypass);

参数定义：

  • bypass=0：开启结果复用。仅在绑定版本、帧编号、区域、模型及其他识别参数相符时命中缓存。
  • bypass=1：绕过结果缓存，每次调用都重新执行相应识别或检测。

返回值：设置成功返回 1；参数不是 0 或 1 时返回 0。

缓存范围：开关在本进程使用的 ZhaoTu.dll 实例内全局共享。关闭识别结果复用不会关闭共享采集帧像素缓存；同一帧仍可能复用已经读回的像素，不必重新从抓图模块读回。OCR 缓存还要求同一 OCR 入口和识别参数；YOLO 的三个检测入口共享检测结果。结果缓存容量有限，条目淘汰后会重新分析。

工作台示例：

SetFrameResultCache(0) // 开启结果复用
SetFrameResultCache(1) // 强制重新分析

C++ 示例：

// 一般保持默认复用；测试每次重新推理时临时绕过缓存。
if (SetFrameResultCache(1) == 1) {
    const FsTongyongJieguo* result = OcrEx(0, 0, 800, 600, "", 0.5);
    // 读取 result 后按接口约定释放。
    FreeResult(result);
}
SetFrameResultCache(0);

完整调用实例：请参阅OCR 模型识别工作流及 YOLO 检测说明。
