绑定、路径与截图函数

BindWindow

函数简介

绑定当前进程的窗口并开始采集画面。

函数原型

int WINAPI BindWindow(HWND hwnd, const char* display, const char* mouse, const char* keypad, int mode);

参数定义

  • hwnd：当前进程的有效窗口句柄。
  • display：采集方式，填写 "dx"、"obs" 或 "wgc"。
  • mouse：接受 "normal"、"windows" 或 "dx"；当前仅校验并保存配置，不执行鼠标操作，建议填写 "normal"。
  • keypad：接受 "normal"、"windows" 或 "dx"；当前仅校验并保存配置，不执行键盘操作，建议填写 "normal"。
  • mode：模式参数，填写 0 或 1。

返回值

整型数：1 表示成功，0 表示失败。

示例

BindWindow(0x实际窗口句柄, "dx", "normal", "normal", 0)

mouse 和 keypad 目前仅作为配置值校验、保存并参与重复绑定比较，不实现鼠标或键盘操作；"dx" 只是可接受的字符串，不代表已实现 DX 鼠标或键盘模式。实际调用建议均填写 "normal"。

UnBindWindow

函数简介

解除当前窗口绑定并停止采集。

函数原型

int WINAPI UnBindWindow(void);

参数定义

无。

返回值

整型数：1 表示成功，0 表示失败；重复解绑也返回成功。

示例

UnBindWindow()

SetPath

函数简介

设置截图文件和图片模板相对路径所使用的目录。

函数原型

int WINAPI SetPath(const char* path);

参数定义

  • path：已存在的目录路径，字符串使用 UTF-8。

返回值

整型数：1 表示设置成功，0 表示路径无效或设置失败。

示例

SetPath("C:\\Users\\Administrator\\Documents\\DaMo\\FsDm")

SetFindBackend

函数简介

选择找图、找色和取色使用 CPU 或 GPU 执行。

函数原型

int WINAPI SetFindBackend(const char* backend);

参数定义

  • backend：填写 "cpu" 或 "gpu"。

返回值

整型数：1 表示设置成功，0 表示参数错误。

示例

SetFindBackend("gpu")

Capture

函数简介

抓取指定区域，可登记为找图模板、保存为 24 位 BMP 位图，或同时执行。

函数原型

int WINAPI Capture(int x1, int y1, int x2, int y2, const char* name, int mode = 2);

参数定义

  • x1：区域左上角 X 坐标。
  • y1：区域左上角 Y 坐标。
  • x2：区域右下角 X 坐标。
  • y2：区域右下角 Y 坐标；右下边界不包含在截图内。
  • name：mode=1 时为模板别名；mode=2 时为文件路径；mode=3 时同时作为模板别名和文件路径。
  • mode：1 仅登记模板，2 仅保存文件，3 同时执行。C++ 和工作台可省略，默认 2；C 或动态调用必须传入 6 个参数。

返回值

整型数：0 表示失败，1 表示成功。

示例

Capture(0, 0, 2000, 2000, "screen.bmp")

mode=1 登记原始截图像素，可直接用 name 调用 FindPic，并由 FreePic 释放。mode=3 若写入文件后模板缓存不足，会返回 0，但不会回滚已保存文件。

CaptureJpg

函数简介

抓取指定区域并保存为 JPEG 图片。

函数原型

int WINAPI CaptureJpg(int x1, int y1, int x2, int y2, const char* name, int mode = 2);

参数定义

  • x1、y1：区域左上角坐标。
  • x2、y2：区域右下角坐标，右下边界不包含。
  • name：模板别名和/或文件路径，具体由 mode 决定。
  • mode：1 仅登记模板，2 仅保存文件，3 同时执行。C++ 和工作台可省略，默认 2；C 或动态调用必须传入 6 个参数。

返回值

整型数：0 表示失败，1 表示成功。

示例

CaptureJpg(0, 0, 2000, 2000, "screen.jpg")

CaptureGif

函数简介

抓取指定区域并保存为动态 GIF 或单帧 GIF。

函数原型

int WINAPI CaptureGif(int x1, int y1, int x2, int y2, const char* file, int delay, int time);

参数定义

  • x1、y1：区域左上角坐标。
  • x2、y2：区域右下角坐标，右下边界不包含。
  • file：GIF 文件名或完整路径。
  • delay：帧间隔，单位为毫秒；0 表示保存单帧。
  • time：录制时长，单位为毫秒；保存单帧时填写 0。

返回值

整型数：0 表示失败，1 表示成功。

示例

CaptureGif(0, 0, 2000, 2000, "screen.gif", 100, 3000)
CaptureGif(0, 0, 2000, 2000, "still.gif", 0, 0)
