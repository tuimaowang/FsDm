SetCaptureFrameInterval

设置输入帧跳过数，或固定当前已发布快照。DX、OBS 按目标窗口的呈现计数，WGC 按帧池取出的输入帧计数。

函数原型

int WINAPI SetCaptureFrameInterval(int interval);

参数与返回值

interval=-1 固定当前已发布快照并暂停发布新快照。后续找图、找色、OCR、CV 找图及其他读取共享采集帧的处理继续读取该快照；固定期间 GetFrameNumber 不递增。需要已有快照，否则返回 0 且设置不变。

interval>=0 表示每次采集后跳过的输入帧数：0 为逐帧采集，1 为跳过 1 帧，2 为跳过 2 帧，以此类推。设置成功后从下一输入帧重新计数；传非负值会解除固定并恢复采集。小于 -1、未绑定或无效参数返回 0，原设置不变。成功返回 1；每次新绑定默认值为 0。

工作台示例

SetCaptureFrameInterval(-1)
SetCaptureFrameInterval(0)
SetCaptureFrameInterval(1)
