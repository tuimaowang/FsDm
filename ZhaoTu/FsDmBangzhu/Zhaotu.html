找图函数

OpenCV 模板匹配提供 CvFindPic 系列函数；AI 图像接口说明 YOLO 目标检测。

四个函数的前七个参数相同。FindPic、FindPicS 返回第一个命中；FindPicEx、FindPicExS 返回全部命中。

dir扫描顺序
0从左到右，从上到下
1从左到右，从下到上
2从右到左，从上到下
3从右到左，从下到上

FindPic

函数简介

在指定区域查找 BMP24、PNG 或 JPG/JPEG 图片模板，返回第一个命中位置。

函数原型

const FsTongyongJieguo* WINAPI FindPic(int x1, int y1, int x2, int y2, const char* pic_name, const char* delta_color, double sim, int dir);

参数定义

  • x1、y1：搜索区域左上角坐标。
  • x2、y2：搜索区域右下角坐标；右下边界不包含在搜索区域内。
  • pic_name：BMP24、PNG 或 JPG/JPEG 模板文件名；多个名称用 | 分隔。
  • delta_color：六位 RGB 颜色容差，例如 "000000" 表示不增加容差。
  • sim：相似度参数，范围 0.1～1.0。
  • dir：扫描方向，填写 0～3，方向见本页表格。

返回值

通用结果指针。status=0 表示执行成功，count=0 表示未命中；count 大于 0 时从 items[0] 读取结果。发生错误时 status 非 0；返回 nullptr 表示分配失败。

示例

const FsTongyongJieguo* r = FindPic(0, 0, 2000, 2000, "button.bmp", "000000", 0.9, 0);
if (r != nullptr) {
    if (r->status == 0 && r->count > 0) {
        int x = r->items[0].x;
        int y = r->items[0].y;
    }
    FreeResult(r);
}

FindPicEx

函数简介

在指定区域查找 BMP24、PNG 或 JPG/JPEG 图片模板，返回全部命中位置。

函数原型

const FsTongyongJieguo* WINAPI FindPicEx(int x1, int y1, int x2, int y2, const char* pic_name, const char* delta_color, double sim, int dir);

参数定义

  • x1、y1：搜索区域左上角坐标。
  • x2、y2：搜索区域右下角坐标，右下边界不包含。
  • pic_name：BMP24、PNG 或 JPG/JPEG 模板文件名；多个名称用 | 分隔。
  • delta_color：六位 RGB 颜色容差，例如 "000000"。
  • sim：相似度参数，范围 0.1～1.0。
  • dir：扫描方向，填写 0～3。

返回值

通用结果指针。status=0 表示执行成功，count 表示命中数量；每个命中位置从 items[i] 读取，最多 1500 项。返回 nullptr 表示分配失败。

示例

const FsTongyongJieguo* r = FindPicEx(0, 0, 2000, 2000, "button.bmp", "000000", 0.9, 0);
if (r != nullptr) {
    if (r->status == 0) {
        for (unsigned int i = 0; i < r->count; ++i) {
            int x = r->items[i].x;
            int y = r->items[i].y;
        }
    }
    FreeResult(r);
}

FreeResult

函数简介

释放一次找图函数返回的结果及其条目。

函数原型

int WINAPI FreeResult(const FsTongyongJieguo* result);

参数定义

  • result：FindPic 系列函数返回的结果指针。

返回值

整型数：1 表示成功，0 表示指针无效；nullptr 也可传入并返回成功。

示例

FreeResult(r)
