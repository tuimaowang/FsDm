MatchPicName

函数简介： 根据文件名和通配符获取 BMP、PNG、JPG/JPEG 文件集合，结果可直接传给 FindPic/FindPicEx 等。

函数原型：


const char* WINAPI MatchPicName(const char* pic_name);

参数定义： pic_name 为 UTF-8 文件名或路径，支持 | 列表、文件名中的 *、?。 相对路径按 SetPath 解析，未设定时按进程当前目录。通配符不能用于目录部分，不递归子目录。

返回值： 匹配到的 BMP、PNG、JPG/JPEG 文件名以 | 分隔，无匹配或错误返回空字符串。 不包含目录、其他扩展名、磁盘上不存在的文件或仅由 LoadPicByte 加载的虚拟模板。 每组匹配按文件名排序，整个列表按输入组顺序拼接，重复文件只保留第一次。 返回名称保留输入的相对目录或绝对路径形式；字符串属于 DLL，后续调用不会覆盖；使用完后调用 FreeAllResults 或 FreeAllStringResults 全量释放。

示例：


SetPath("C:\Users\Administrator\Documents\DaMo\FsDm")
MatchPicName("abc???.bmp|icon*.png|photo*.jpg")

假设目录内有 abc001.bmp、abc002.bmp，MatchPicName("abc*.bmp") 返回 abc001.bmp|abc002.bmp。

注意： 只枚举 BMP、PNG、JPG/JPEG 扩展名（不区分大小写），不会解码验证文件内容。BMP 找图模板仍要求有效 BMP24；PNG/JPG/JPEG 必须能由系统图像解码器解码。无需绑定窗口，不预加载模板，不创建 GPU 设备。工作台显示文件枚举和其他耗时。

完整调用实例：请参阅MatchPicName 所属工作流，其中包含前置设置、调用及结果/资源处理。
