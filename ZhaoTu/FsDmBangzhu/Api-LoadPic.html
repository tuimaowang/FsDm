LoadPic

函数简介：

预先加载 BMP24、PNG 或 JPG/JPEG 文件模板到内存，供后续找图直接复用。

函数原型：


int WINAPI LoadPic(const char* pic_name);

参数定义：

  • pic_name：BMP24、PNG 或 JPG/JPEG 模板名称，支持 | 列表及文件名中的 *、? 通配符；目录部分不支持通配符。

返回值：

  • 1：全部指定模板加载成功。
  • 0：至少有一项失败；此前已成功加载的项仍保留。

示例：


LoadPic("test.bmp|icon.png|photo.jpg")

注意： 无需绑定。显式缓存不自动淘汰，模板数量按需增长，并受 SetTemplateCacheLimit 设置的 CPU 字节预算约束。默认预算为 256 MiB。加载后不再检查源文件；要更新请 FreePic 后重新加载。GPU 模板首次查找时按需上传，并受每个 GPU 设备各自的同值预算约束。

SetTemplateCacheLimit

函数简介：

设置找图模板缓存的字节预算。模板数量没有固定上限，但仍受缓存预算和可用内存、显存约束。

函数原型：

int WINAPI SetTemplateCacheLimit(uint64_t bytes);

参数定义：

  • bytes：大于 0 的字节数；默认值为 268435456（256 MiB）。

返回值：

  • 1：设置成功。
  • 0：参数为 0、超出平台可表示范围，或新预算小于当前显式预加载模板的 CPU 占用；失败时保留原配置。

示例：

SetTemplateCacheLimit(536870912); // 512 MiB

预算规则： CPU 缓存和每个 GPU 设备缓存分别使用该字节预算，不合并计算；它不是进程总内存上限。降低预算时会淘汰普通 CPU 缓存和 GPU 最近较少使用的模板。正在执行的查找继续使用其模板，相关资源在查找结束后回收。

完整调用实例：请参阅LoadPic 所属工作流，其中包含前置设置、调用及结果/资源处理。
