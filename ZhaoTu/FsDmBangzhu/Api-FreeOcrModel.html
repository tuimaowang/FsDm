FreeOcrModel

函数简介：

移除指定模型登记并释放其会话资源。

函数原型：


int WINAPI FreeOcrModel(int index);

参数定义：

  • index：模型编号，0～99。

返回值：

  • 1：清理成功；有效但未登记的编号也可清理。
  • 0：编号无效等。

示例：


FreeOcrModel(1)

注意： 正在执行的识别保留引用，可安全完成。清理后使用该编号需重新 SetOcrModel；清理 0 号也不会再次自动登记默认模型。共用 DirectML 设备保持复用。

完整调用实例：请参阅FreeOcrModel 所属工作流，其中包含前置设置、调用及结果/资源处理。
